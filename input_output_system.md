
# Поток ввода-вывода (stream)

## Объект типа ostream
**Вывод (запись).**


Получает значения различных типов, преобразует их в последовательность символов и передает их через буфер в определенное место для вывода (консоль, файл, сетевые интерфейсы).

## Объект типа istream
**Ввод (чтение)**


Получает через буфер из определенного места последовательности символов (с консоли, из файла, из сети) и преобразует эти последовательности в значения различных типов.
