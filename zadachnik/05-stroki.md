# Тема 5. Строки

Текст — это данные, с которыми вы будете работать чаще всего: имена, логины,
команды, строки файла. Здесь вы научитесь перебирать символы, искать подстроку,
разрезать строку на части и читать строку целиком (с пробелами). `std::string`
в C++ удобен — забудьте про `char[]` из старых учебников.

> 📖 **Опирается на раздел 10 справочника** ([теория в справочнике](../ref/05-stroki.md)).
> Там про `std::string`, поиск, `substr`, разбиение на слова и `getline`.

> 🔗 **В целых программах:** «Проверка пароля» (`../examples/09-parol.md`) — перебор символов
> и `<cctype>`; «Анализ текста» (`../examples/03-analiz-teksta.md`) — разбор строки на слова.

## Чему вы здесь научитесь

- Перебирать символы строки (`for (char c : s)`) и приводить регистр.
- Работать с индексами «с двух концов» (палиндром, разворот).
- Искать символ (`find`) и вырезать часть (`substr`).
- Читать строку целиком через `getline` и делить её на слова.

## Где это пригодится

Разбор текста — это ввод пользователя, парсинг конфигов (`ключ=значение`), обработка
CSV, поиск в логах, нормализация имён. Практически любая программа где-то трогает
строки. Приёмы «два указателя с краёв» и «найти разделитель и разрезать» универсальны
далеко за пределами строк.

---

## 5.1. Гласные в слове 🟢

Дано слово из латинских букв. Посчитайте, сколько в нём гласных (`a`, `e`, `i`, `o`,
`u`) в любом регистре.

**Формат ввода.** Одно слово без пробелов (латиница), длиной до 100 символов.

**Формат вывода.** Количество гласных.

**Пример:**
```
Ввод
Programming
Вывод
3
```

**Что тренирует:** перебор символов строки, приведение регистра, счётчик по условию.
**Где пригодится:** любой посимвольный анализ текста: подсчёт, фильтрация, статистика по буквам.
**Как подступиться:** пройдите по каждому символу; приведите к нижнему регистру; сравните с набором гласных.

---

## 5.2. Переворот строки 🟢

Напечатайте слово задом наперёд.

**Формат ввода.** Одно слово без пробелов, до 100 символов.

**Формат вывода.** То же слово, записанное в обратном порядке.

**Пример:**
```
Ввод
hello
Вывод
olleh
```

**Что тренирует:** обход строки с конца или готовый `std::reverse`.
**Где пригодится:** разворот данных, проверка симметрии, база для более сложных строковых задач.
**Как подступиться:** есть два пути — `std::reverse` или ручной цикл с конца. Попробуйте оба.

> При ручном обходе индекс держите в `int` (`i >= 0`), иначе для беззнакового типа условие всегда истинно и цикл не остановится.

---

## 5.3. Палиндром? 🟡

Определите, читается ли слово одинаково слева направо и справа налево.

**Формат ввода.** Одно слово без пробелов, до 100 символов.

**Формат вывода.** `YES`, если это палиндром, иначе `NO`.

**Пример 1:**
```
Ввод
level
Вывод
YES
```
**Пример 2:**
```
Ввод
world
Вывод
NO
```

**Что тренирует:** приём «два указателя» — движение с двух краёв к центру.
**Где пригодится:** проверка симметрии, сравнение с зеркальной копией; «два указателя» — базовый алгоритмический приём для массивов.
**Как подступиться:** сравнивайте `word[left]` и `word[right]`, сдвигая границы к центру; расхождение — сразу `NO`.

---

## 5.4. Ключ и значение 🟡

Дана строка вида `имя=значение` (без пробелов, ровно один знак `=`). Напечатайте имя
и значение на отдельных строках.

**Формат ввода.** Строка `ключ=значение`, например `count=42`.

**Формат вывода.** Две строки: сначала часть до `=`, потом часть после.

**Пример:**
```
Ввод
count=42
Вывод
count
42
```

**Что тренирует:** поиск разделителя (`find`) и разрезание строки (`substr`).
**Где пригодится:** разбор конфигов (`.ini`, `.env`), параметров URL, CSV, любых форматов «поле=значение».
**Как подступиться:** найдите позицию `=`, возьмите часть до неё и часть после.

---

## 5.5. Сколько слов в предложении 🔴

Дана строка с несколькими словами, разделёнными пробелами. Посчитайте количество
слов. Слова могут быть разделены несколькими пробелами подряд, а в начале и конце
строки пробелы тоже возможны.

**Формат ввода.** Одна строка (может содержать пробелы), до 1000 символов.

**Формат вывода.** Количество слов.

**Пример:**
```
Ввод
  привет   мир  как дела
Вывод
4
```

**Что тренирует:** чтение целой строки (`getline`) и разбиение на слова через поток.
**Где пригодится:** подсчёт слов в тексте, токенизация ввода, обработка CSV с «грязными» пробелами.
**Как подступиться:** `cin >> s` прочитает лишь одно слово — нужен `getline` на всю строку, а затем разбор.

> Здесь `std::cin >> s` не годится — он прочитает только одно слово. Нужна вся строка.

---

## 5.6. Инвертировать регистр 🟡

Дана строка. Напечатайте её, поменяв регистр каждой буквы на противоположный:
строчные — в заглавные, заглавные — в строчные. Прочие символы не меняются.

**Формат ввода.** Одна строка (латиница, цифры, пробелы), до 200 символов.

**Формат вывода.** Та же строка с инвертированным регистром букв.

**Пример:**
```
Ввод
Hello World 42
Вывод
hELLO wORLD 42
```

**Что тренирует:** изменение символов строки «на месте» (`for (char &c : s)`) и функции `std::toupper`/`std::tolower`.
**Где пригодится:** нормализация ввода, «шуточные» фильтры, преобразование текста по правилу.
**Как подступиться:** читайте всю строку через `getline`. Перебирайте символы **по ссылке**; для каждой буквы применяйте `toupper` или `tolower` в зависимости от её текущего регистра (`std::isupper`/`std::islower`).

---

## 5.7. Самый частый символ 🟡

Дана строка из строчных латинских букв. Напечатайте символ, который встречается чаще
всех. Если таких несколько, напечатайте наименьший по алфавиту.

**Формат ввода.** Одно слово из строчных латинских букв, до 1000 символов.

**Формат вывода.** Один символ — самый частый (при равенстве — наименьший).

**Пример:**
```
Ввод
banana
Вывод
a
```

**Что тренирует:** подсчёт частот и аккуратный разбор ничьей (правило выбора при равенстве).
**Где пригодится:** статистика по данным, мода в выборке, простое сжатие, анализ логов.
**Как подступиться:** заведите массив счётчиков на 26 букв (`int cnt[26] = {}`), пройдитесь по строке, увеличивая `cnt[c - 'a']`. Затем найдите индекс с наибольшим счётчиком; перебирая от `'a'` к `'z'`, вы автоматически получите наименьший при равенстве.

---

## 5.8. Развернуть слова в предложении 🔴

Дана строка из слов, разделённых пробелами. Напечатайте слова в обратном порядке,
разделяя одним пробелом.

**Формат ввода.** Одна строка со словами (латиница), до 1000 символов.

**Формат вывода.** Те же слова в обратном порядке, через один пробел.

**Пример:**
```
Ввод
the quick brown fox
Вывод
fox brown quick the
```

**Что тренирует:** `getline`, разбиение на слова и работу с `vector<string>`.
**Где пригодится:** обработка текста, переворот порядка элементов, разбор команд.
**Как подступиться:** соберите слова в `vector`, затем разверните его и печатайте по порядку.

# Подсказки

> 📖 Мало подсказки? Откройте теорию темы: [раздел справочника](../ref/05-stroki.md).

<details>
<summary>5.1 — Гласные в слове</summary>

- Перебирайте символы: `for (char c : word) { ... }`.
- Приведите к нижнему регистру для проверки: `char lc = std::tolower(static_cast<unsigned char>(c));` (из `<cctype>`), потом сравнивайте `lc` с `'a'`, `'e'`, `'i'`, `'o'`, `'u'`.
- На каждой гласной увеличивайте счётчик.
</details>

<details>
<summary>5.2 — Переворот строки</summary>

- Способ 1: `std::reverse(word.begin(), word.end());` из `<algorithm>`, потом вывести.
- Способ 2 (вручную): печатайте символы с конца — `for (int i = word.size() - 1; i >= 0; --i) std::cout << word[i];`. Осторожно: индекс должен быть знаковым (`int`), иначе `i >= 0` для беззнакового всегда истинно.
</details>

<details>
<summary>5.3 — Палиндром</summary>

- Сравнивайте пару символов «с краёв к центру»: `left = 0`, `right = size() - 1`.
- Пока `left < right`: если `word[left] != word[right]` — это не палиндром (`NO`), иначе сдвигайте `++left; --right;`. Дошли до центра без расхождений — `YES`.
- Или проще: сделайте копию, переверните её и сравните со строкой (`==`).
</details>

<details>
<summary>5.4 — Ключ и значение</summary>

- Найдите позицию знака: `std::size_t pos = s.find('=');`.
- Ключ — всё до неё: `s.substr(0, pos)`. Значение — всё после: `s.substr(pos + 1)`.
- Печатайте каждую часть с новой строки.
</details>

<details>
<summary>5.5 — Сколько слов</summary>

- Читайте всю строку: `std::string line; std::getline(std::cin, line);`.
- Самый простой способ посчитать слова — отдать строку в поток: `std::istringstream iss(line);` (из `<sstream>`), потом `std::string w; while (iss >> w) ++count;`. Оператор `>>` сам пропускает лишние пробелы.
</details>

<details>
<summary>5.6 — Инвертировать регистр</summary>

- Читайте всю строку: `std::getline(std::cin, line);`.
- Перебирайте **по ссылке**: `for (char &c : line) { ... }`.
- Внутри: `if (std::isupper(static_cast<unsigned char>(c))) c = std::tolower(...); else if (std::islower(...)) c = std::toupper(...);` (всё из `<cctype>`, с приведением к `unsigned char`).
</details>

<details>
<summary>5.7 — Самый частый символ</summary>

- Счётчики: `int cnt[26] = {};`. Проход: `for (char c : s) ++cnt[c - 'a'];`.
- Найдите лучший индекс: заведите `int best = 0;` и `for (int i = 1; i < 26; ++i) if (cnt[i] > cnt[best]) best = i;`.
- Строгое `>` (а не `>=`) при переборе от `'a'` даёт наименьший символ при равенстве. Ответ — `char('a' + best)`.
</details>

<details>
<summary>5.8 — Развернуть слова</summary>

- Читайте всю строку: `std::getline(std::cin, line);`.
- Разбейте на слова через `std::istringstream` и соберите в `std::vector<std::string>`.
- `std::reverse(words.begin(), words.end());`, затем печатайте слова через пробел (без пробела после последнего).
</details>

## Проверьте себя (мини тест-план)

- **5.1:** слово без гласных (`bcd` → `0`); все заглавные.
- **5.2:** слово из одной буквы; слово-палиндром (`level` → `level`).
- **5.3:** одна буква (палиндром); чётная длина (`abba` → `YES`, `abca` → `NO`).
- **5.4:** пустое значение (`x=` → `x` и пустая строка); значение с цифрами.
- **5.5:** пустая строка (`0`); много пробелов подряд; пробелы по краям.
- **5.6:** только цифры и пробелы (не меняются); смешанный регистр.
- **5.7:** все буквы разные (ответ — `a`); явный лидер (`aaab` → `a`); ничья (`ab` → `a`).
- **5.8:** одно слово (выводится как есть); лишние пробелы между словами схлопываются.

✅ Тема закрыта, когда «найти и разрезать» и «пройти по символам» вы делаете не подглядывая в справочник.
