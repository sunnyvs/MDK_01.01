# Тема 2. Ввод и вывод

Программа почти всегда что-то читает и что-то печатает. Здесь вы научитесь делать
это надёжно: читать заранее неизвестное количество чисел, останавливаться по сигналу
или по концу ввода и выводить результат ровно так, как требуют (нужная точность,
ширина поля). Кривой ввод-вывод — причина половины «странных» багов.

> 📖 **Опирается на раздел 4 справочника** ([теория в справочнике](../ref/02-vvod-vyvod.md)).
> Там разобраны безопасное чтение, `getline`, `std::format` и почему `cin` иногда «ломается».

> 🔗 **Тот же приём в целой программе:** «Угадай число» (`../examples/04-ugaday-chislo.md`) —
> чтение ввода в цикле и реакция на каждое значение.

## Чему вы здесь научитесь

- Три способа читать поток чисел: «известно сколько», «до стоп-значения», «до конца ввода».
- Правильно заводить накопитель суммы (`long long`) и счётчик.
- Форматировать вывод: ширина поля (`setw`), точность (`setprecision`, `fixed`).
- Не начинать поиск максимума с нуля (типовая ошибка).

## Где это пригодится

Любая программа обработки данных читает поток значений неизвестной длины: строки
лога, показания датчиков, числа из файла, ответы пользователя. Умение корректно
остановиться и аккуратно вывести — базовый навык, отличающий работающую программу
от «зависла и печатает одно и то же».

---

## 2.1. Сумма N чисел 🟢

Сначала дано, сколько будет чисел, затем сами числа. Напечатайте их сумму.

**Формат ввода.** Первое число `N` (0 ≤ N ≤ 1000), затем `N` целых чисел.

**Формат вывода.** Одно число — сумма всех `N` чисел.

**Пример:**
```
Ввод
4
10 20 30 40
Вывод
100
```

**Что тренирует:** цикл «фиксированное число повторений» и накопление суммы.
**Где пригодится:** подсчёт итога по списку (сумма чека, суммарный вес, общее время).
**Как подступиться:** прочитайте `N`, заведите `long long sum = 0`, крутите цикл ровно `N` раз.

---

## 2.2. Пока не ноль 🟢

Читайте числа по одному, пока не встретится `0`. Ноль — это сигнал «стоп», в
подсчёте он не участвует. Напечатайте, сколько чисел было и какова их сумма.

**Формат ввода.** Последовательность целых чисел, заканчивающаяся нулём.

**Формат вывода.** Два числа через пробел: количество чисел (без нуля) и их сумма.

**Пример:**
```
Ввод
5 3 8 0
Вывод
3 16
```

**Что тренирует:** цикл с «сигнальным» (sentinel) значением — выход по `break`.
**Где пригодится:** ввод «вводите товары, пустая строка — конец», меню «0 — выход», чтение до маркёра конца.
**Как подступиться:** читайте в бесконечном цикле, а на стоп-значении делайте `break` **до** того, как учтёте его.

---

## 2.3. Максимум до конца ввода 🟡

Читайте числа, пока ввод не закончится (файл кончился или нажали `Ctrl+Z` и
`Enter`). Напечатайте наибольшее из них. Гарантируется, что хотя бы одно число будет.

**Формат ввода.** Одно или несколько целых чисел, разделённых пробелами и переводами строк, до конца ввода.

**Формат вывода.** Наибольшее число.

**Пример:**
```
Ввод
3 -1 7 4 7 2
Вывод
7
```

**Что тренирует:** чтение «пока получается» (`while (std::cin >> x)`) и корректную инициализацию максимума.
**Где пригодится:** обработка файла или потока неизвестной длины; поиск рекорда, пика, самой поздней даты.
**Как подступиться:** сам факт удачного чтения — это условие цикла. Максимум нельзя начинать с `0`.

---

## 2.4. Ровный столбик 🟡

Дано число `N`, затем `N` целых чисел. Напечатайте их **по одному в строке**,
выровняв по правому краю в поле шириной 6 символов.

**Формат ввода.** `N` (0 ≤ N ≤ 100), затем `N` целых чисел, по модулю до 99999.

**Формат вывода.** `N` строк, в каждой одно число, прижатое к правому краю поля из 6 символов.

**Пример:**
```
Ввод
3
5 -142 30000
Вывод
     5
  -142
 30000
```

**Что тренирует:** форматированный вывод фиксированной ширины (`std::setw`).
**Где пригодится:** таблицы, отчёты, выравнивание чисел в столбик, ценники, любой человекочитаемый вывод.
**Как подступиться:** `setw` действует только на **следующий** вывод — ставьте его перед каждым числом.

---

## 2.5. Среднее с двумя знаками 🟡

Дано число `N`, затем `N` дробных чисел. Напечатайте их сумму и среднее
арифметическое, каждое — ровно с двумя знаками после запятой.

**Формат ввода.** `N` (1 ≤ N ≤ 1000), затем `N` дробных чисел.

**Формат вывода.** Два числа через пробел: сумма и среднее, по два знака после точки.

**Пример:**
```
Ввод
3
1.5 2 2.5
Вывод
6.00 2.00
```

**Что тренирует:** работу с `double` в цикле и стойкую настройку точности вывода.
**Где пригодится:** финансовые отчёты (всегда две цифры после точки), средние показатели, проценты.
**Как подступиться:** копите в `double`; `std::fixed` + `setprecision(2)` задаются один раз и держатся до конца.

---

## 2.6. Гистограмма из звёздочек 🟡

Дано число `N`, затем `N` неотрицательных целых чисел. Для каждого напечатайте
строку: само число в поле шириной 3, вертикальную черту и столько звёздочек `*`,
каково значение.

**Формат ввода.** `N` (0 ≤ N ≤ 100), затем `N` целых чисел от 0 до 40.

**Формат вывода.** `N` строк вида `«число | звёздочки»`.

**Пример:**
```
Ввод
3
5 0 8
Вывод
  5 | *****
  0 | 
  8 | ********
```

**Что тренирует:** вложенный цикл (внешний — по числам, внутренний — по звёздочкам) вместе с форматированным выводом.
**Где пригодится:** простая визуализация данных в консоли, прогресс-бары, ASCII-графики, отладочный вывод «на глаз».
**Как подступиться:** внешний цикл читает и печатает число с `setw(3)` и `" | "`, внутренний печатает `x` звёздочек; при нуле внутренний цикл просто не выполнится.

---

## 2.7. Второй по величине 🔴

Читайте числа до конца ввода. Напечатайте **второе по величине** значение —
то, что идёт сразу за максимумом. Гарантируется, что различных чисел хотя бы два.

**Формат ввода.** Целые числа до конца ввода.

**Формат вывода.** Второе по величине число.

**Пример:**
```
Ввод
3 9 9 5 9 7
Вывод
7
```

**Что тренирует:** отслеживание **двух** «рекордов» за один проход и аккуратную обработку повторов.
**Где пригодится:** «серебряный призёр», вторая по цене позиция, антипик — везде, где важен не только максимум.
**Как подступиться:** держите две переменные — `best` и `second`. При новом числе больше `best` старый `best` становится `second`. Повтор максимума (`x == best`) не должен опускаться в `second`. Начальные значения удобно взять из первых прочитанных чисел, а не из нуля.

---

## 2.8. Мин, макс и среднее за проход 🔴

Читайте числа до конца ввода (хотя бы одно число будет). За **один** проход
посчитайте и напечатайте минимум, максимум и среднее (с двумя знаками).

**Формат ввода.** Целые числа до конца ввода.

**Формат вывода.** Три величины через пробел: минимум, максимум и среднее.

**Пример:**
```
Ввод
2 9 4 9 1
Вывод
1 9 5.00
```

**Что тренирует:** одновременное ведение нескольких накопителей и защиту от неверной инициализации.
**Где пригодится:** сводка по данным (мониторинг, метрики, показания за сутки) без второго прохода и без хранения всего массива.
**Как подступиться:** ведите `count`, `sum` (в `long long`), `mn` и `mx`. Первое число задаёт стартовые `mn` и `mx` — не берите их с нуля. Среднее считайте после цикла: `static_cast<double>(sum) / count`.

# Подсказки

> 📖 Мало подсказки? Откройте теорию темы: [раздел справочника](../ref/02-vvod-vyvod.md).

<details>
<summary>2.1 — Сумма N чисел</summary>

- Прочитайте `N`, заведите `long long sum = 0;`, крутите цикл `for (int i = 0; i < N; ++i)`.
- Внутри: `int x; std::cin >> x; sum += x;`.
</details>

<details>
<summary>2.2 — Пока не ноль</summary>

- Цикл с «сигнальным» значением: `while (true) { std::cin >> x; if (x == 0) break; ... }`.
- Внутри, до `break`, увеличивайте счётчик и сумму — тогда сам ноль не попадёт в подсчёт.
</details>

<details>
<summary>2.3 — Максимум до конца ввода</summary>

- Сам поток в условии значит «удалось прочитать?»: `while (std::cin >> x) { ... }`.
- Прочитайте **первое** число до цикла (или заведите флаг «чисел ещё не было»), чтобы было с чем сравнивать. Обновляйте: `if (x > best) best = x;`.
- Не начинайте `best` с `0` — если все числа отрицательные, ответ будет неверным.
</details>

<details>
<summary>2.4 — Ровный столбик</summary>

- Ширина поля: `#include <iomanip>`, затем `std::cout << std::setw(6) << x << "\n";`.
- `setw` действует только на **следующий** вывод, поэтому пишите его перед каждым числом.
- По умолчанию выравнивание идёт вправо — как раз то, что нужно.
</details>

<details>
<summary>2.5 — Среднее с двумя знаками</summary>

- Читайте числа в `double`, копите в `double sum`.
- Среднее: `sum / N`. Приводить к `double` не нужно — `sum` уже дробное.
- Два знака: `std::cout << std::fixed << std::setprecision(2) << sum << " " << avg;` или `std::format("{:.2f} {:.2f}", sum, avg)`.
</details>

<details>
<summary>2.6 — Гистограмма из звёздочек</summary>

- Внешний цикл: прочитали `x`, напечатали `std::setw(3) << x << " | "`.
- Внутренний цикл печатает звёздочки: `for (int j = 0; j < x; ++j) std::cout << '*';`, затем перевод строки.
- При `x == 0` внутренний цикл не выполнится — получится пустой «столбик».
</details>

<details>
<summary>2.7 — Второй по величине</summary>

- Две переменные: `best` (максимум) и `second` (второй). Инициализируйте их первыми двумя числами (большее — в `best`).
- Для каждого следующего `x`: если `x > best` — `second = best; best = x;`; иначе если `x < best && x > second` — `second = x;`.
- Условие `x < best` защищает от повторов максимума: `9` во второй раз не должно стать «вторым».
</details>

<details>
<summary>2.8 — Мин, макс и среднее за проход</summary>

- Заведите `int count = 0; long long sum = 0; int mn, mx;`.
- Первое прочитанное число задаёт `mn` и `mx`; дальше обновляйте `if (x < mn) mn = x;` и `if (x > mx) mx = x;`.
- Среднее после цикла: `double avg = static_cast<double>(sum) / count;`, вывод — `std::fixed` + `setprecision(2)`.
</details>

## Проверьте себя (мини тест-план)

- **2.1:** `N = 0` — сумма `0`, цикл не выполняется ни разу.
- **2.2:** сразу `0` — количество `0`, сумма `0`; отрицательные числа в потоке.
- **2.3:** все числа отрицательные (`-5 -2 -9` → `-2`) — вот где ломается `best = 0`.
- **2.6:** значение `0` (пустой столбик); одно большое значение (`40` звёздочек); `N = 0`.
- **2.7:** максимум повторяется (`9 9 5` → `5`, а не `9`); ровно два разных числа; отрицательные.
- **2.8:** одно число (мин = макс = среднее); одинаковые числа; отрицательные (тест на инициализацию `mn`/`mx`).

✅ Тема закрыта, когда все три способа чтения (по счётчику, до стоп-значения, до конца) вы пишете не задумываясь.
