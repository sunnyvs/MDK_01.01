# Тема 10. Перепиши по-современному

Много кода в интернете, учебниках и старых репозиториях написано в стиле «до 2011 года».
Он **работает**, поэтому его надо уметь читать — но так уже не пишут. В этой теме вы берёте
рабочий, но устаревший фрагмент и переписываете на современный C++. Это тренирует то, что не
тренирует «напиши с нуля»: **узнавать старьё и видеть современную замену**.

## Чему вы здесь научитесь

- **Узнавать** устаревшие конструкции в чужом коде — половина кода вокруг именно такая.
- Заменять их на современные: почему `vector` вместо `new[]`, `std::` вместо `using namespace std;`.
- Понимать **не только «как», но и «почему»** — каждая замена чинит конкретную проблему (утечки, конфликты имён, отсутствие проверки типов).

## Где это пригодится

Читать чужой код придётся всегда — в туториалах, на форумах, в проектах, к которым вы
присоединяетесь. Умение мгновенно опознать «о, это старьё, я знаю современную замену»
отличает того, кто просто копирует, от того, кто понимает. И собственный код вы сразу
будете писать правильно.

## Как работать с темой

Здесь нет «Формата ввода» — вход у программ прежний. Задача одна: **тот же результат, но
современным кодом**. Собирайте со строгими флагами и добивайтесь **нуля предупреждений** —
часто именно они и подсказывают, что старый код делал что-то сомнительное.

**⭐ Бонус** под задачей — дополнительная старая привычка, которую стоит заменить в том же фрагменте.

## 10.1. `using namespace std;` 🟢

Перепишите так, чтобы не было `using namespace std;`.

```cpp
#include <iostream>
using namespace std;

int main() {
    int count;
    cout << "Сколько? ";
    cin >> count;
    cout << "Ввели: " << count << endl;
}
```

**Что тренирует:** явные имена из `std`, привычку не тащить всё пространство имён разом.
**Где пригодится:** любой файл, который вы пишете; в заголовках `using namespace` вообще запрещён.
**Как подступиться:** уберите строку `using namespace std;` и допишите `std::` перед `cout`, `cin`, `endl`. Заодно посмотрите на имя `count` — оно совпадает с `std::count` из `<algorithm>`, и с `using namespace` это могло бы конфликтовать.
**⭐ Бонус:** заодно замените `endl` на `"\n"` — `endl` лишний раз сбрасывает буфер.

## 10.2. `new[]` / `delete[]` → `std::vector` 🟡

Перепишите, убрав ручное управление памятью.

```cpp
#include <iostream>

int main() {
    int n;
    std::cin >> n;

    int* arr = new int[n];          // выделили руками
    for (int i = 0; i < n; ++i)
        arr[i] = i * i;

    long long sum = 0;
    for (int i = 0; i < n; ++i)
        sum += arr[i];

    std::cout << sum << "\n";
    delete[] arr;                   // забудете — утечка
}
```

**Что тренирует:** `std::vector` вместо ручной памяти; идею RAII.
**Где пригодится:** любой динамический массив; `new[]`/`delete[]` в современном коде почти не встречается.
**Как подступиться:** замените `new int[n]` на `std::vector<int> arr(n);`. Строка `delete[]` больше не нужна — память освободится сама.
**⭐ Бонус:** посчитайте сумму через `std::accumulate` из `<numeric>` вместо второго цикла.

## 10.3. `char[]` и `strcpy` → `std::string` 🟡

Перепишите работу с текстом на `std::string`.

```cpp
#include <iostream>
#include <cstring>

int main() {
    char name[50];
    std::strcpy(name, "Аня");       // длина не проверяется — переполните буфер и не заметите
    std::strcat(name, " Иванова");

    std::cout << name << " (" << std::strlen(name) << " байт)\n";
}
```

**Что тренирует:** `std::string` вместо C-строк; безопасную работу с текстом.
**Где пригодится:** везде, где есть текст; C-строки — источник переполнений буфера.
**Как подступиться:** `std::string name = "Аня";`, склейка — обычным `+`/`+=`, длина — `name.size()`. Заголовок `<cstring>` больше не нужен.
**⭐ Бонус:** добавьте к имени отчество через `getline` (ввод с пробелами) — с `char[]` это была бы боль.

## 10.4. `#define` и C-style cast 🟡

Перепишите, убрав макрос и C-приведение.

```cpp
#include <iostream>

#define SIZE 10                     // препроцессор: не знает типов и области видимости

int main() {
    int sum = 45;
    double avg = (double)sum / SIZE; // C-style cast

    std::cout << avg << "\n";
}
```

**Что тренирует:** `const` вместо `#define`, `static_cast` вместо `(тип)`.
**Где пригодится:** любые константы; C-cast молча делает опасные преобразования, `static_cast` — только осмысленные.
**Как подступиться:** `const int SIZE = 10;` внутри `main`, и `static_cast<double>(sum)` вместо `(double)sum`.
**⭐ Бонус:** если константа известна на этапе компиляции — попробуйте `constexpr int SIZE = 10;`.

## 10.5. `printf`-таблица → потоки 🔴

Перепишите ввод-вывод на потоки, сохранив выравнивание столбцов.

```cpp
#include <cstdio>

int main() {
    int n;
    scanf("%d", &n);                 // легко перепутать спецификатор и тип
    for (int i = 0; i < n; ++i) {
        char name[50];
        int score;
        scanf("%s %d", name, &score);
        printf("%-10s | %3d\n", name, score);  // %d для double = мусор, и никто не поймает
    }
}
```

**Что тренирует:** `std::cin`/`std::cout` вместо `scanf`/`printf` и форматирование столбцов средствами потоков (`setw`, `left`).
**Где пригодится:** любой табличный вывод; `printf`/`scanf` не сверяют тип с форматом и работают с сырыми `char[]`.
**Как подступиться:** читайте `std::cin >> name >> score;` в `std::string`/`int`. Формат `%-10s` (влево, ширина 10) — это `std::left << std::setw(10)`; `%3d` — `std::right << std::setw(3)` (оба из `<iomanip>`). Не забудьте вернуть выравнивание, если оно «залипает».
**⭐ Бонус:** соберите строку через `std::format("{:<10} | {:>3}", name, score)` из `<format>` — та же краткость, что у `printf`, но с проверкой типов.

## 10.6. Полный рефакторинг 🔴

Перед вами маленькая, но насквозь устаревшая программа: она бросает `n` кубиков и печатает
сумму и среднее. Перепишите её целиком на современный C++, убрав **все** старые приёмы сразу.

```cpp
#include <iostream>
#include <cstdlib>
#include <ctime>
using namespace std;

int main() {
    srand(time(nullptr));
    int n;
    cin >> n;

    int* dice = new int[n];
    for (int i = 0; i < n; ++i)
        dice[i] = rand() % 6 + 1;    // перекошенное распределение

    int total = 0;
    for (int i = 0; i < n; ++i)
        total += dice[i];

    double avg = (double)total / n;
    cout << "sum=" << total << " avg=" << avg << endl;
    delete[] dice;
}
```

**Что тренирует:** видеть в одном фрагменте **несколько** устаревших конструкций и заменять их согласованно.
**Где пригодится:** реальный рефакторинг почти всегда такой — старый код набит сразу несколькими привычками, и чинить их приходится вместе.
**Как подступиться:** пройдитесь по списку замен: `using namespace std;` → явное `std::`; `new[]`/`delete[]` → `std::vector<int>`; `rand() % 6 + 1` → `<random>` (`std::mt19937` + `std::uniform_int_distribution`); `(double)total` → `static_cast<double>`; `endl` → `"\n"`. Результат на том же `n` должен остаться прежним по смыслу (числа случайные, но сумма/среднее считаются так же).
**⭐ Бонус:** посчитайте сумму через `std::accumulate`, а бросок вынесите в функцию `int roll(std::mt19937 &gen)`.

# Подсказки

> 📖 Мало подсказки? Откройте теорию темы: [раздел справочника](../ref/09-spravka.md).

<details>
<summary>10.1 — using namespace std;</summary>

Уберите строку `using namespace std;`. Перед каждым именем из библиотеки поставьте `std::`:
`std::cout`, `std::cin`. `endl` — это `std::endl`, но его лучше заменить на `"\n"`.
</details>

<details>
<summary>10.2 — new[] / delete[]</summary>

`std::vector<int> arr(n);` создаёт вектор из `n` нулей. Дальше `arr[i]` работает как у массива.
Строку `delete[] arr;` удалите — вектор освобождает память сам на выходе из `main`.
</details>

<details>
<summary>10.3 — char[] и strcpy</summary>

`std::string name = "Аня";`, затем `name += " Иванова";`. Длина — `name.size()`.
Заголовок `<cstring>` можно убрать. `std::string` сам следит за размером — переполнить буфер нечем.
</details>

<details>
<summary>10.4 — #define и C-cast</summary>

`const int SIZE = 10;` (или `constexpr`) вместо `#define`. `static_cast<double>(sum)` вместо `(double)sum`.
`static_cast` откажется от бессмысленного преобразования, а `(тип)` сделает что угодно молча.
</details>

<details>
<summary>10.5 — printf-таблица</summary>

- Чтение: `int n; std::cin >> n;`, затем в цикле `std::string name; int score; std::cin >> name >> score;`.
- Вывод столбцов: `std::cout << std::left << std::setw(10) << name << " | " << std::right << std::setw(3) << score << "\n";` (нужен `<iomanip>`).
- `std::left`/`std::right` «залипают» на потоке — при желании возвращайте выравнивание обратно.
</details>

<details>
<summary>10.6 — Полный рефакторинг</summary>

```cpp
#include <iostream>
#include <vector>
#include <numeric>
#include <random>

int main() {
    int n;
    std::cin >> n;

    std::mt19937 gen(std::random_device{}());
    std::uniform_int_distribution<int> dice(1, 6);

    std::vector<int> rolls(n);
    for (int &r : rolls) r = dice(gen);

    long long total = std::accumulate(rolls.begin(), rolls.end(), 0LL);
    double avg = static_cast<double>(total) / n;
    std::cout << "sum=" << total << " avg=" << avg << "\n";
}
```
Ни `new`/`delete`, ни `using namespace`, ни `rand()`, ни C-cast — и память освобождается сама.
</details>

## Проверьте себя

Тема закрыта, когда:

- в переписанном коде **нет** ни `using namespace std;`, ни `new`/`delete`, ни `char[]` с `strcpy`, ни `#define` для констант, ни `printf`/`scanf`, ни `rand()`;
- всё собирается со строгими флагами **без единого предупреждения**;
- результат совпадает со старой версией (тот же вывод на том же вводе; для 10.6 — та же логика подсчёта суммы и среднего).

✅ Настоящая проверка: вы сможете взять любой чужой фрагмент из интернета и с ходу сказать, что в нём устарело и чем это заменить.
