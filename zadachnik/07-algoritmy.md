# Тема 7. Итераторы и алгоритмы

Стандартная библиотека умеет сортировать, искать, считать и фильтровать — вам не нужно
писать это руками. Здесь вы научитесь пользоваться `std::sort`, `count_if`,
`min/max_element` и задавать своё правило через лямбду. Это переход от «я пишу циклы»
к «я комбинирую готовые кубики» — так пишут в реальных проектах.

> 📖 **Опирается на разделы 17–18 справочника** ([теория в справочнике](../ref/07-algoritmy.md)).
> Там про `begin()/end()`, `sort`, `count_if`, `find_if`, лямбды и типичные ловушки (`*max_element`, `0LL`).

> 🔗 **В целой программе:** «Журнал оценок» (`../examples/08-zhurnal-ocenok.md`) — сортировка
> структур по полю и вывод лучших.

## Чему вы здесь научитесь

- Сортировать `vector` по возрастанию и по своему правилу (лямбда-компаратор).
- Считать элементы по условию (`count_if`) и суммировать (`accumulate`).
- Захватывать переменные в лямбду (`[avg]`).
- Сортировать вектор структур по нескольким полям сразу.

## Где это пригодится

Сортировка и фильтрация — хлеб любой обработки данных: топ-N результатов, поиск
подходящих записей, ранжирование. Лямбды и алгоритмы делают код короче и надёжнее
ручных циклов (меньше места для ошибки на единицу). Правило «сортировать по нескольким
критериям» встречается в любой таблице с сортировкой по колонкам.

---

## 7.1. Отсортировать по возрастанию 🟢

Дано `N` чисел. Напечатайте их по возрастанию в одну строку через пробел.

**Формат ввода.** `N` (0 ≤ N ≤ 100000), затем `N` целых чисел.

**Формат вывода.** Числа по возрастанию через пробел.

**Пример:**
```
Ввод
5
3 1 4 1 5
Вывод
1 1 3 4 5
```

**Что тренирует:** базовый вызов `std::sort` над `vector`.
**Где пригодится:** любой упорядоченный вывод; сортировка — предподготовка для медианы, бинарного поиска, дедупликации.
**Как подступиться:** `std::sort(v.begin(), v.end());` — и печатайте.

---

## 7.2. По убыванию 🟡

То же, что и предыдущая, но по **убыванию**. Используйте `std::sort` с собственным
правилом сравнения (лямбдой).

**Формат ввода.** `N` (0 ≤ N ≤ 100000), затем `N` целых чисел.

**Формат вывода.** Числа по убыванию через пробел.

**Пример:**
```
Ввод
5
3 1 4 1 5
Вывод
5 4 3 1 1
```

**Что тренирует:** лямбда-компаратор — своё правило «кто раньше».
**Где пригодится:** «сначала самые дорогие/новые/крупные»; любое нестандартное упорядочивание.
**Как подступиться:** передайте третьим аргументом `[](int a, int b){ return a > b; }`.

---

## 7.3. Сколько больше среднего 🔴

Дано `N` чисел. Напечатайте, сколько из них **строго больше** среднего
арифметического всей последовательности.

**Формат ввода.** `N` (1 ≤ N ≤ 100000), затем `N` целых чисел.

**Формат вывода.** Количество чисел, больших среднего.

**Пример:**
```
Ввод
5
1 2 3 4 100
Вывод
1
```

**Что тренирует:** два прохода (сначала среднее, потом счёт), `accumulate` + `count_if` с захватом.
**Где пригодится:** статистика «выше среднего»: успеваемость, зарплаты, аномалии в данных.
**Как подступиться:** сначала посчитайте среднее по всем; потом посчитайте, сколько строго больше него. Среднее захватите в лямбду.

> Среднее здесь `22`, больше него только `100`.

---

## 7.4. Медиана 🟡

Дано `N` чисел (`N` нечётное). Медиана — это число, оказавшееся ровно посередине,
если все числа отсортировать. Напечатайте медиану.

**Формат ввода.** Нечётное `N` (1 ≤ N ≤ 99999), затем `N` целых чисел.

**Формат вывода.** Медиана.

**Пример:**
```
Ввод
5
7 1 3 9 5
Вывод
5
```

**Что тренирует:** сортировку как подготовительный шаг и обращение по центральному индексу.
**Где пригодится:** медиана устойчивее среднего к выбросам — её используют в статистике зарплат, времени отклика, цен.
**Как подступиться:** отсортируйте, возьмите элемент с индексом `N / 2` (для нечётного `N` это ровно середина).

---

## 7.5. Топ-3 по баллам 🔴

Даны `N` участников: имя и баллы. Напечатайте имена трёх лучших по баллам. При
равенстве баллов выше тот, чьё имя меньше по алфавиту. Если участников меньше трёх —
напечатайте всех.

**Формат ввода.** `N` (1 ≤ N ≤ 100000), затем `N` пар: имя (латиница) и целое число баллов.

**Формат вывода.** До трёх строк — имена лучших, по одному в строке, в порядке убывания баллов.

**Пример:**
```
Ввод
4
anna 40
boris 55
vera 55
igor 20
Вывод
boris
vera
anna
```

**Что тренирует:** сортировку вектора структур по двум критериям сразу.
**Где пригодится:** лидерборды, топ-N результатов поиска, рейтинги с тай-брейком.
**Как подступиться:** заведите `struct`, отсортируйте правилом «по баллам убыв., при равенстве по имени возр.», выведите первые три.

> `boris` и `vera` по 55; `boris` меньше по алфавиту, поэтому он первый.

---

## 7.6. Минимум и максимум одной строкой 🟢

Дано `N` чисел. Напечатайте минимум и максимум, используя `std::min_element` и
`std::max_element`.

**Формат ввода.** `N` (1 ≤ N ≤ 100000), затем `N` целых чисел.

**Формат вывода.** Два числа через пробел: минимум и максимум.

**Пример:**
```
Ввод
5
3 1 4 1 5
Вывод
1 5
```

**Что тренирует:** готовые алгоритмы поиска и разыменование итератора (`*`).
**Где пригодится:** границы диапазона, экстремумы — без ручного цикла.
**Как подступиться:** `min_element` возвращает **итератор** (указатель на элемент); значение достаётся звёздочкой `*`.

---

## 7.7. Сколько чётных 🟡

Дано `N` чисел. Напечатайте, сколько среди них чётных, используя `std::count_if`.

**Формат ввода.** `N` (0 ≤ N ≤ 100000), затем `N` целых чисел.

**Формат вывода.** Количество чётных чисел.

**Пример:**
```
Ввод
5
1 2 3 4 6
Вывод
3
```

**Что тренирует:** `count_if` с лямбдой-условием.
**Где пригодится:** «сколько подходящих» по любому признаку (активные пользователи, товары в наличии).
**Как подступиться:** правило чётности передайте лямбдой прямо в `count_if`.

---

## 7.8. Слова по длине 🔴

Дано `N` слов. Напечатайте их отсортированными: сначала короткие, при равной длине —
по алфавиту. По одному слову в строке.

**Формат ввода.** `N` (1 ≤ N ≤ 100000), затем `N` слов (латиница).

**Формат вывода.** `N` строк — слова в нужном порядке.

**Пример:**
```
Ввод
4
banana kiwi fig apple
Вывод
fig
kiwi
apple
banana
```

**Что тренирует:** сортировку по вычисляемому ключу (длина) с тай-брейком по алфавиту.
**Где пригодится:** ранжирование по нескольким критериям, «сначала короткие/дешёвые/новые».
**Как подступиться:** компаратор: если длины разные — сравниваем длины, иначе сравниваем сами строки.

# Подсказки

> 📖 Мало подсказки? Откройте теорию темы: [раздел справочника](../ref/07-algoritmy.md).

<details>
<summary>7.1 — По возрастанию</summary>

- Считайте в `std::vector<int> v`, затем `std::sort(v.begin(), v.end());` (из `<algorithm>`).
- Печатайте в цикле через пробел.
</details>

<details>
<summary>7.2 — По убыванию</summary>

- Та же сортировка, но с правилом: `std::sort(v.begin(), v.end(), [](int a, int b){ return a > b; });`.
- Лямбда `[](int a, int b){ return a > b; }` читается как «`a` должно идти раньше `b`, если оно больше».
- Альтернатива: отсортировать по возрастанию и печатать с конца.
</details>

<details>
<summary>7.3 — Больше среднего</summary>

- Сумму удобно взять через `std::accumulate(v.begin(), v.end(), 0LL)` (из `<numeric>`; `0LL` — чтобы копилось в `long long`).
- Среднее — дробное: `double avg = (double)sum / v.size();`.
- Посчитайте подходящие: `std::count_if(v.begin(), v.end(), [avg](int x){ return x > avg; });`. Обратите внимание: `avg` захвачено в `[avg]`, чтобы лямбда его видела.
</details>

<details>
<summary>7.4 — Медиана</summary>

- Отсортируйте вектор, ответ — элемент с индексом `N / 2` (целочисленное деление для нечётного `N` как раз даёт середину: при `N = 5` это индекс 2).
</details>

<details>
<summary>7.5 — Топ-3</summary>

- Заведите `struct P { std::string name; int score; };` и `std::vector<P>`.
- Сортируйте своим правилом: сначала по баллам убыванию, при равенстве — по имени возрастанию: `return a.score != b.score ? a.score > b.score : a.name < b.name;`.
- Напечатайте первые `std::min(3, (int)v.size())` имён.
</details>

<details>
<summary>7.6 — Минимум и максимум одной строкой</summary>

- `int mn = *std::min_element(v.begin(), v.end());` — не забудьте `*` (иначе получите итератор, а не число).
- Аналогично `*std::max_element(...)`.
</details>

<details>
<summary>7.7 — Сколько чётных</summary>

- `std::count_if(v.begin(), v.end(), [](int x){ return x % 2 == 0; });`.
- Результат — целое (тип `long long`/`ptrdiff_t`), его можно сразу печатать.
</details>

<details>
<summary>7.8 — Слова по длине</summary>

- Читайте в `std::vector<std::string>`.
- Компаратор: `if (a.size() != b.size()) return a.size() < b.size(); return a < b;`.
- Печатайте по слову в строке.
</details>

## Проверьте себя (мини тест-план)

- **7.1 / 7.2:** `N = 0` — пустой вывод; уже отсортированный массив; все одинаковые.
- **7.3:** все числа равны (никто не «больше среднего» → `0`); отрицательные числа.
- **7.4:** `N = 1` (медиана — само число); проверьте, что индекс именно `N / 2`.
- **7.5:** участников меньше трёх (вывести всех); тай-брейк по имени (равные баллы).
- **7.6:** `N = 1` (минимум равен максимуму); все одинаковые; отрицательные.
- **7.7:** ни одного чётного (`0`); все чётные; помните, что `0` — чётное.
- **7.8:** слова одинаковой длины (идут по алфавиту); уже отсортированный ввод.

✅ Тема закрыта, когда вместо ручного цикла вы первым делом вспоминаете подходящий алгоритм из `<algorithm>`.
