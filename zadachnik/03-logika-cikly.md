# Тема 3. Логика, ветвления, циклы

Здесь программа впервые начинает «принимать решения» и «повторять действия».
Ветвления (`if`, `switch`) и циклы — это скелет любой логики. Заодно вы закрепите
пару `/` и `%`, на которой держится половина арифметических задач.

> 📖 **Опирается на разделы 5–8 справочника** ([теория в справочнике](../ref/03-logika-cikly.md)).
> Там разобраны ловушки чисел, `=` против `==`, забытый `break`, `<` против `<=`.

> 🔗 **В живых программах:** «Угадай число» (`../examples/04-ugaday-chislo.md`) — цикл до победы
> и ветвления «больше/меньше»; «Калькулятор» (`../examples/01-kalkulyator.md`) — выбор действия через `switch`.

## Чему вы здесь научитесь

- Строить цепочки ветвлений `if / else if / else` и группировать `case` в `switch`.
- Раскладывать число на цифры циклом (`% 10`, `/ 10`).
- Писать вложенные циклы (цикл внутри цикла) и понимать, кто за что отвечает.
- Оптимизировать перебор (проверка простоты до корня, а не до `n`).

## Где это пригодится

Ветвление — это «в зависимости от…» в любой программе: роль пользователя, тип файла,
результат проверки. Циклы — это «для каждого…»: обработать все строки, все пиксели,
все дни. Разбор числа на цифры — классика собеседований и основа контрольных сумм
(проверка номера карты, ISBN, штрихкода).

## 3.1. Знак и чётность 🟢

Дано целое число. Напечатайте две характеристики: положительное оно, отрицательное
или ноль, и чётное оно или нечётное.

**Формат ввода.** Одно целое число, по модулю до 10^9.

**Формат вывода.** Два слова через пробел:
- первое — `POSITIVE`, `NEGATIVE` или `ZERO`;
- второе — `EVEN` или `ODD`.

**Пример 1:**
```
Ввод
-4
Вывод
NEGATIVE EVEN
```
**Пример 2:**
```
Ввод
0
Вывод
ZERO EVEN
```

**Что тренирует:** цепочку `if / else if / else` и проверку чётности через `%`.
**Где пригодится:** валидация ввода, разбиение на категории, «каждый второй элемент».
**Как подступиться:** знак и чётность — две **независимые** проверки, считайте их отдельно.

---

## 3.2. Время года по месяцу 🟢

Дан номер месяца. Напечатайте, к какому времени года он относится. Решите задачу
через `switch`.

**Формат ввода.** Целое число от 1 до 12.

**Формат вывода.** Одно слово: `WINTER`, `SPRING`, `SUMMER` или `AUTUMN`. Если число вне диапазона 1–12 — напечатайте `ERROR`.

**Пример 1:**
```
Ввод
1
Вывод
WINTER
```
**Пример 2:**
```
Ввод
10
Вывод
AUTUMN
```

**Что тренирует:** `switch` с группировкой `case` и обработкой «всё остальное» (`default`).
**Где пригодится:** меню, разбор кода команды, сопоставление «номер → категория».
**Как подступиться:** несколько `case` подряд без `break` — законный способ сказать «любой из этих».

---

## 3.3. Сумма цифр 🟡

Напечатайте сумму цифр неотрицательного целого числа.

**Формат ввода.** Одно неотрицательное целое число, не превосходящее 10^18.

**Формат вывода.** Сумма его цифр.

**Пример:**
```
Ввод
12345
Вывод
15
```

**Что тренирует:** извлечение цифр числа через `% 10` и `/ 10` в цикле.
**Где пригодится:** контрольные суммы (карты, штрихкоды), нумерология, разбор идентификаторов.
**Как подступиться:** последняя цифра — `n % 10`, «отрезать» её — `n /= 10`. Повторяйте, пока `n > 0`.

> Диапазон до 10^18 — намёк на выбор типа: `int` тут не подойдёт.

---

## 3.4. Простое число? 🟡

Определите, является ли число простым (делится только на 1 и на само себя и при этом
больше 1).

**Формат ввода.** Одно целое число от 1 до 2 000 000 000.

**Формат вывода.** `YES`, если число простое, иначе `NO`.

**Пример 1:**
```
Ввод
7
Вывод
YES
```
**Пример 2:**
```
Ввод
1
Вывод
NO
```

**Что тренирует:** ранний выход из цикла и оптимизацию перебора до `√n`.
**Где пригодится:** криптография (простые — её основа), хеш-таблицы, разложение на множители.
**Как подступиться:** не перебирайте все делители до `n` — достаточно до корня. Подумайте, почему, и как записать `i * i <= n` вместо `i <= sqrt(n)`.

> При больших `n` выражение `i * i` может переполнить `int` — держите `i` в `long long` или сравнивайте `i <= n / i`.

---

## 3.5. Треугольник из звёздочек 🟡

Дана высота `n`. Напечатайте прямоугольный треугольник из символов `*`: в первой
строке одна звёздочка, во второй две, и так до `n`.

**Формат ввода.** Одно целое число `n` (1 ≤ n ≤ 50).

**Формат вывода.** `n` строк со звёздочками.

**Пример:**
```
Ввод
4
Вывод
*
**
***
****
```

**Что тренирует:** вложенный цикл — внешний по строкам, внутренний по символам.
**Где пригодится:** любой двумерный вывод: таблицы, сетки, ASCII-графика, поля игр.
**Как подступиться:** внешний цикл — строка `row` от 1 до `n`; внутренний печатает `row` звёздочек; после него — перевод строки.

---

## 3.6. Гипотеза Коллатца 🔴

Возьмите число `n` и повторяйте: если оно чётное — делите на 2, если нечётное —
умножайте на 3 и прибавляете 1. Рано или поздно получится 1. Напечатайте, сколько
шагов на это потребуется, и наибольшее значение, которого достигла
последовательность по пути.

**Формат ввода.** Одно целое число `n` (1 ≤ n ≤ 1 000 000).

**Формат вывода.** Два числа через пробел: количество шагов до 1 и максимум, достигнутый по дороге (включая само `n`).

**Пример:**
```
Ввод
6
Вывод
8 16
```

**Что тренирует:** цикл `while` с условием-выходом, ветвление внутри цикла и одновременное отслеживание счётчика и максимума.
**Где пригодится:** любые итеративные процессы «повторяй, пока не сойдётся»: моделирование, численные методы, обход состояний.
**Как подступиться:** крутите `while (n != 1)`; на каждом шаге по чётности выбирайте действие, увеличивайте счётчик и обновляйте максимум. Промежуточное `3 * n + 1` может стать большим — держите `n` в `long long`.

> Для `n = 6`: `6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1` — восемь шагов, максимум `16`.

---

## 3.7. Количество делителей 🟡

Напечатайте, сколько у числа делителей (включая 1 и само число).

**Формат ввода.** Одно целое число `n` (1 ≤ n ≤ 10^9).

**Формат вывода.** Количество делителей.

**Пример:**
```
Ввод
12
Вывод
6
```

**Что тренирует:** перебор до корня и приём «делители ходят парами».
**Где пригодится:** теория чисел, разложение, оптимизация перебора вообще.
**Как подступиться:** каждый делитель `i ≤ √n` даёт парный `n / i`. Осторожно с точным квадратом — там пара совпадает.

> Делители 12: 1, 2, 3, 4, 6, 12 — шесть штук.

---

## 3.8. Ёлочка 🔴

Дана высота `n`. Напечатайте пирамиду из звёздочек по центру: в строке `i` сначала
идут пробелы, затем нечётное число звёздочек (1, 3, 5, …).

**Формат ввода.** Одно целое число `n` (1 ≤ n ≤ 50).

**Формат вывода.** `n` строк — пирамида, выровненная «домиком».

**Пример:**
```
Ввод
4
Вывод
   *
  ***
 *****
*******
```

**Что тренирует:** два цикла внутри одного — пробелы и звёздочки по отдельности.
**Где пригодится:** любой центрированный вывод и ASCII-графика.
**Как подступиться:** в строке `row` (от 1 до `n`) сначала `n − row` пробелов, потом `2·row − 1` звёздочек.

# Подсказки

> 📖 Мало подсказки? Откройте теорию темы: [раздел справочника](../ref/03-logika-cikly.md).

<details>
<summary>3.1 — Знак и чётность</summary>

- Знак — обычная цепочка `if (n > 0) ... else if (n < 0) ... else ...`.
- Чётность — остаток от деления на 2: `n % 2 == 0` значит чётное.
- Осторожно: `%` с отрицательными числами может дать `-1` для нечётных. Надёжнее проверять `n % 2 == 0` (чётное), а всё остальное считать нечётным.
</details>

<details>
<summary>3.2 — Время года</summary>

- `switch (month)` и группируйте `case`-ы: `case 12: case 1: case 2: std::cout << "WINTER"; break;`.
- Несколько `case` подряд без `break` — это законный способ сказать «любой из этих».
- Всё, что не 1–12, ловите в `default: std::cout << "ERROR";`.
</details>

<details>
<summary>3.3 — Сумма цифр</summary>

- Тип: `long long n;` (10^18 в `int` не влезет).
- Последняя цифра — `n % 10`, отрезаем её через `n /= 10`.
- Цикл `while (n > 0) { sum += n % 10; n /= 10; }`. Для `n == 0` ответ `0` — проверьте, что не сломается.
</details>

<details>
<summary>3.4 — Простое число</summary>

- Сразу отсеките `n <= 1` → `NO`.
- Перебирайте делители от 2, пока `i * i <= n`. Если нашёлся делитель (`n % i == 0`) — число составное.
- `i * i` при больших `n` может переполнить `int` — держите `i` в `long long` либо сравнивайте `i <= n / i`.
- Дошли до конца без делителей — число простое.
</details>

<details>
<summary>3.5 — Треугольник</summary>

- Внешний цикл по строкам: `for (int row = 1; row <= n; ++row)`.
- Внутренний печатает `row` звёздочек: `for (int j = 0; j < row; ++j) std::cout << '*';`.
- После внутреннего цикла — перевод строки `std::cout << "\n";`.
</details>

<details>
<summary>3.6 — Гипотеза Коллатца</summary>

- Тип `long long n;` — `3 * n + 1` может вырасти.
- `long long steps = 0, mx = n;` и цикл `while (n != 1) { if (n % 2 == 0) n /= 2; else n = 3 * n + 1; ++steps; if (n > mx) mx = n; }`.
- Максимум обновляйте **после** пересчёта `n` (или сравнивайте оба значения) — важно не пропустить пиковое `3 * n + 1`.
</details>

<details>
<summary>3.7 — Количество делителей</summary>

- Перебирайте `i` от 1, пока `i * i <= n` (держите `i` в `long long`).
- Если `n % i == 0` — это сразу два делителя: `i` и `n / i`, прибавляйте `2`.
- Если `i == n / i` (точный квадрат), пара совпала — вычтите один лишний.
</details>

<details>
<summary>3.8 — Ёлочка</summary>

- Внешний цикл: `for (int row = 1; row <= n; ++row)`.
- Первый внутренний печатает `n - row` пробелов, второй — `2 * row - 1` звёздочек.
- После двух внутренних циклов — перевод строки.
</details>

## Проверьте себя (мини тест-план)

- **3.1:** `0` (должно быть `ZERO EVEN`); отрицательное нечётное (`-3` → `NEGATIVE ODD`).
- **3.2:** `0` и `13` — оба должны дать `ERROR`; граничные `2`, `3`, `11`, `12`.
- **3.3:** `0` → `0` (цикл `while (n > 0)` не выполнится — это верный ответ); максимальное 18-значное.
- **3.4:** `1` → `NO`, `2` → `YES`, большое простое (`1000000007` → `YES`).
- **3.6:** `1` → `0 1` (шагов нет); `2` → `1 2`; проверьте, что максимум учитывает пик (`7` даёт максимум `52`).
- **3.7:** `1` → `1`; простое число → `2`; точный квадрат (`16` → `5`) — проверьте, что корень не посчитан дважды.
- **3.8:** `n = 1` — одна звёздочка без пробелов слева.

✅ Тема закрыта, когда вложенный цикл и `switch` вы пишете без шпаргалки, а разбор числа на цифры — на автомате.
