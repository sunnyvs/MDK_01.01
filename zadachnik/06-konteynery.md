# Тема 6. Контейнеры: vector, map, set, pair

Контейнеры — это готовые «умные хранилища» стандартной библиотеки. Вместо того чтобы
вручную городить массивы и счётчики, вы берёте `vector` (список), `map` (словарь
«ключ → значение»), `set` (множество уникальных) — и решаете задачу в несколько строк.
Это водораздел между «пишу как на паскале» и «пишу на C++».

> 📖 **Опирается на разделы 11–15 справочника** ([теория в справочнике](../ref/06-konteynery.md)).
> Там про `vector`, `map` как счётчик, `set`, `pair` и типичные ловушки (`m[key]` создаёт ключ!).

> 🔗 **В целых программах:** «Анализ текста» (`../examples/03-analiz-teksta.md`) — `map`-счётчик
> и топ по частоте; «Список дел» (`../examples/02-spisok-del.md`) — `vector` структур;
> «Телефонная книга» (`../examples/06-telefonnaya-kniga.md`) — `map` с сохранением между запусками.

## Чему вы здесь научитесь

- Хранить список значений в `vector` и обходить его.
- Считать частоты через `map` (`++freq[key]`) — приём номер один в обработке данных.
- Находить количество уникальных через `set`.
- Понимать, что `map` хранит ключи **отсортированными** — и как это использовать.

## Где это пригодится

`map`-счётчик — это буквально «сколько раз встретилось» для чего угодно: слова в
тексте, коды ошибок в логе, товары в заказах, голоса на выборах. `vector` — самый
частый контейнер вообще. `set` — «убрать дубликаты» и «сколько разных». Эти три
структуры покрывают огромную долю реальных задач обработки данных.

## 6.1. Массив наоборот 🟢

Дано `N` чисел. Напечатайте их в обратном порядке в одну строку через пробел.

**Формат ввода.** `N` (0 ≤ N ≤ 1000), затем `N` целых чисел.

**Формат вывода.** Те же числа в обратном порядке, через пробел.

**Пример:**
```
Ввод
5
1 2 3 4 5
Вывод
5 4 3 2 1
```

**Что тренирует:** заполнение `vector` и обход с конца.
**Где пригодится:** «последние сначала» (лента новостей, история), базовая работа со списком.
**Как подступиться:** считайте в `vector`, затем печатайте от последнего индекса к нулевому.

---

## 6.2. Сколько различных 🟢

Дано `N` чисел. Напечатайте, сколько среди них **различных**.

**Формат ввода.** `N` (0 ≤ N ≤ 100000), затем `N` целых чисел.

**Формат вывода.** Количество различных значений.

**Пример:**
```
Ввод
6
3 1 3 2 1 3
Вывод
3
```

**Что тренирует:** `set` как хранилище уникальных значений.
**Где пригодится:** «сколько уникальных посетителей», «сколько разных товаров», дедупликация.
**Как подступиться:** сложите все числа в `set` — он сам отбросит повторы; ответ — его размер.

---

## 6.3. Самое частое слово 🟡

Дано `N` слов. Напечатайте слово, которое встречается чаще всего. Если таких
несколько, напечатайте наименьшее по алфавиту.

**Формат ввода.** `N` (1 ≤ N ≤ 100000), затем `N` слов (латиница, без пробелов).

**Формат вывода.** Одно слово — самое частое.

**Пример:**
```
Ввод
5
apple pear apple pear banana
Вывод
apple
```

**Что тренирует:** `map` как счётчик частот и поиск максимума с учётом правила при равенстве.
**Где пригодится:** топ-запросы, самый популярный товар, анализ логов, «горячие» ключи.
**Как подступиться:** посчитайте частоты в `map`; `map` отсортирован по ключу, поэтому при обходе первым запомнится алфавитно меньшее.

> `apple` и `pear` встречаются по 2 раза; `apple` меньше по алфавиту, поэтому он.

---

## 6.4. Ведомость оценок 🟡

Дано `N` оценок (числа от 2 до 5). Напечатайте, сколько раз встретилась каждая оценка
— по возрастанию оценки.

**Формат ввода.** `N` (0 ≤ N ≤ 100000), затем `N` чисел от 2 до 5.

**Формат вывода.** По одной строке на каждую оценку от 2 до 5 в формате `оценка: количество`. Печатайте все четыре оценки, даже если какой-то не было (тогда количество `0`).

**Пример:**
```
Ввод
6
5 4 5 3 5 4
Вывод
2: 0
3: 1
4: 2
5: 3
```

**Что тренирует:** массив-счётчик по фиксированному диапазону значений.
**Где пригодится:** гистограммы, распределения (звёзды рейтинга, возрастные группы), подсчёт по категориям.
**Как подступиться:** заведите счётчик на индексы 2..5, увеличивайте по оценке, потом выведите все четыре — включая нулевые.

---

## 6.5. Победитель по очкам 🟡

Даны `N` записей вида «имя очки». Напечатайте имя участника с наибольшим числом
очков. Гарантируется, что победитель один.

**Формат ввода.** `N` (1 ≤ N ≤ 100000), затем `N` пар: строка-имя и целое число очков.

**Формат вывода.** Имя победителя.

**Пример:**
```
Ввод
3
anna 40
boris 55
vera 33
Вывод
boris
```

**Что тренирует:** параллельное чтение пары «строка + число» и поиск максимума по одному полю.
**Где пригодится:** «кто набрал больше всех», лидерборд, поиск рекордсмена в потоке данных.
**Как подступиться:** можно вообще без контейнера — держите `bestName` и `bestScore`, обновляйте при большем счёте.

## 6.6. Первый неповторяющийся 🔴

Дано `N` чисел. Напечатайте **первое** (в порядке ввода) число, которое встречается
ровно один раз. Если такого нет — напечатайте `-1`.

**Формат ввода.** `N` (0 ≤ N ≤ 100000), затем `N` целых чисел.

**Формат вывода.** Первое неповторяющееся число или `-1`.

**Пример:**
```
Ввод
6
4 5 4 6 5 7
Вывод
6
```

**Что тренирует:** совмещение двух проходов — сначала частоты (`map`), затем поиск в **исходном** порядке.
**Где пригодится:** «первый уникальный запрос», обнаружение единичных событий, дедупликация с сохранением порядка.
**Как подступиться:** сохраните числа в `vector` и параллельно посчитайте частоты в `map`. Затем пройдите по `vector` (именно по нему — он хранит порядок ввода) и верните первое число с частотой 1.

> В примере `4` и `5` повторяются, `6` — первое встретившееся с единственным вхождением.

## 6.7. Суммы по категориям 🟡

Даны `N` записей вида «категория сумма» (категория — слово). Для каждой категории
напечатайте её суммарное значение, по алфавиту категорий.

**Формат ввода.** `N` (1 ≤ N ≤ 100000), затем `N` пар: слово-категория и целое число.

**Формат вывода.** По строке на категорию (в алфавитном порядке): `категория сумма`.

**Пример:**
```
Ввод
4
food 100
transport 50
food 200
food 30
Вывод
food 330
transport 50
```

**Что тренирует:** `map` как аккумулятор по ключу (`total[key] += value`).
**Где пригодится:** агрегация расходов, суммы продаж по товарам, любые отчёты «итого по группе».
**Как подступиться:** `map<string, long long>`; прибавляйте сумму к нужному ключу; обойдите `map` в конце.

---

## 6.8. Пересечение множеств 🔴

Даны два набора чисел. Напечатайте, сколько **различных** чисел встречается в обоих
наборах одновременно.

**Формат ввода.** `N`, затем `N` чисел; затем `M`, затем `M` чисел.

**Формат вывода.** Количество различных общих чисел.

**Пример:**
```
Ввод
3
1 2 3
4
2 3 4 5
Вывод
2
```

**Что тренирует:** два `set` и проверку принадлежности одного в другом.
**Где пригодится:** общие элементы (общие друзья, совпадающие теги, пересечение прав доступа).
**Как подступиться:** оба набора — в `set` (это сразу убирает дубликаты); пройдите по первому и считайте тех, кто есть во втором.

> Общие числа: `2` и `3` — их два.

<details>
<summary>6.1 — Массив наоборот</summary>

- Считайте в `std::vector<int> v(N);` циклом `for (int i = 0; i < N; ++i) std::cin >> v[i];`.
- Печатайте с конца: `for (int i = v.size() - 1; i >= 0; --i)`. Индекс держите в `int` (см. тему «Строки»).
</details>

<details>
<summary>6.2 — Сколько различных</summary>

- `std::set<int>` хранит только уникальные значения. Добавляйте каждое число: `s.insert(x);`.
- Ответ — это `s.size()`.
</details>

<details>
<summary>6.3 — Самое частое слово</summary>

- Считайте частоты в `std::map<std::string, int> freq;` — `++freq[word];`.
- Пройдите по `freq` (он отсортирован по ключу!) и запомните слово с максимальным счётчиком. Идёте по возрастанию алфавита, поэтому при равенстве первым запомнится наименьшее — как раз нужно.
- Обновляйте только при **строго большем** счётчике: `if (count > best) { best = count; answer = word; }`.
</details>

<details>
<summary>6.4 — Ведомость оценок</summary>

- Проще всего массив-счётчик: `int cnt[6] = {0};` и `++cnt[grade];` (индексы 2..5 заняты).
- Затем цикл `for (int g = 2; g <= 5; ++g) std::cout << g << ": " << cnt[g] << "\n";`.
- Печатаете все оценки от 2 до 5, даже нулевые — так требует условие.
</details>

<details>
<summary>6.5 — Победитель по очкам</summary>

- Задачу можно решить и без контейнера: читайте пары и держите `bestName`, `bestScore`, обновляя их, когда очки больше текущего максимума.
- Инициализируйте `bestScore` очень маленьким числом (или значением первой записи), чтобы отрицательные очки не сломали сравнение.
</details>

<details>
<summary>6.6 — Первый неповторяющийся</summary>

- Первый проход: `std::vector<int> v(N);` читаете и заодно `++cnt[x];`, где `cnt` — `std::map<int,int>` (или `unordered_map`).
- Второй проход — по `v`: `for (int x : v) if (cnt[x] == 1) { ответ = x; break; }`.
- Порядок ввода хранит именно `vector`; по `map` идти нельзя — он отсортирован. Если подходящего нет — выведите `-1`.
</details>

<details>
<summary>6.7 — Суммы по категориям</summary>

- `std::map<std::string, long long> total;`.
- В цикле: `total[cat] += amount;` — при первом обращении ключ создастся сам со значением 0.
- В конце обойдите `map` (он по алфавиту): `for (const auto &[cat, sum] : total) ...`.
</details>

<details>
<summary>6.8 — Пересечение множеств</summary>

- Два `std::set<int> a, b;` — заполните из двух наборов (дубликаты уйдут сами).
- Пройдите по `a` и считайте: `for (int x : a) if (b.count(x)) ++count;`.
</details>

## Проверьте себя (мини тест-план)

- **6.1:** `N = 0` — пустой вывод; `N = 1` — одно число.
- **6.2:** все числа одинаковые (`1`); все разные; `N = 0` → `0`.
- **6.3:** все слова разные (ответ — алфавитно первое); одно слово повторяется.
- **6.4:** какой-то оценки нет вовсе (должна вывестись с `0`); `N = 0` — все нули.
- **6.5:** отрицательные очки у всех — вот где ломается `bestScore = 0`; один участник.
- **6.6:** все числа повторяются (`-1`); все уникальны (первое из ввода); `N = 0` → `-1`.
- **6.7:** одна категория; несколько категорий; проверьте суммирование повторов одной категории.
- **6.8:** нет общих (`0`); все общие; дубликаты во втором наборе (не считаются дважды).
