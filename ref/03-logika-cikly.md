## 5. Арифметика и её ловушки

```cpp
int a = 7;
int b = 2;

std::cout << a + b << "\n";   // → 9
std::cout << a - b << "\n";   // → 5
std::cout << a * b << "\n";   // → 14
std::cout << a / b << "\n";   // → 3   ⚠️ не 3.5!
std::cout << a % b << "\n";   // → 1   остаток от деления, только для целых

++a;                          // a стало 8   (то же, что a = a + 1)
a += 5;                       // a стало 13  (то же, что a = a + 5)
a *= 2;                       // a стало 26
```

### Ловушка 1: целочисленное деление

Если **оба** операнда целые — результат целый, дробная часть отбрасывается (не округляется!).

```cpp
int a = 7, b = 2;

std::cout << a / b << "\n";           // → 3     отбросили 0.5
std::cout << 7 / 2.0 << "\n";         // → 3.5   один операнд дробный — всё считается в double
std::cout << 1.0 * a / b << "\n";     // → 3.5   умножили на 1.0, чтобы «поднять» тип
std::cout << static_cast<double>(a) / b << "\n";  // → 3.5   явно и понятно

double wrong = a / b;                 // ❌ → 3   деление уже произошло в int,
                                      //    результат 3 положили в double — поздно
double right = 1.0 * a / b;           // ✅ → 3.5
```

**Реальная ситуация — средний балл:**

```cpp
int sum = 17;
int count = 5;

double avgBad = sum / count;                                    // ❌ → 3
double avgOk = static_cast<double>(sum) / count;                // ✅ → 3.4
std::cout << std::fixed << std::setprecision(1) << avgOk;       // → 3.4
```

### Ловушка 2: `%` с отрицательными числами

```cpp
std::cout << 7 % 3 << "\n";     // →  1
std::cout << -7 % 3 << "\n";    // → -1   знак берётся от ЛЕВОГО операнда
std::cout << 7 % -3 << "\n";    // →  1

// Из-за этого «чётность» через % работает, а «последняя цифра» — нет
int n = -1234;
std::cout << n % 10 << "\n";           // → -4   с минусом!
std::cout << std::abs(n) % 10 << "\n"; // →  4   ✅ сначала abs
```

### Ловушка 3: сравнение дробных на равенство

```cpp
double a = 0.1 + 0.2;

std::cout << (a == 0.3) << "\n";                  // → 0   то есть false!
std::cout << std::setprecision(20) << a << "\n";  // → 0.30000000000000004440892098501

// ✅ Сравнивай с допуском
const double EPS = 1e-9;                          // «достаточно близко»
std::cout << (std::abs(a - 0.3) < EPS) << "\n";   // → 1   то есть true
```

Причина: `0.1` в двоичной системе бесконечная дробь — как `1/3` в десятичной. Компьютер хранит ближайшее приближение, и погрешности накапливаются.

### Ловушка 4: деление на ноль

```cpp
int n = 10, d = 0;

std::cout << n / d;              // ❌ программа обрывается МОЛЧА, без сообщения
                                 //    (в Windows — код выхода 0xC0000094)

if (d != 0)                      // ✅ проверяй перед делением
  std::cout << n / d;
else
  std::cout << "Деление на ноль\n";

double x = 10.0, y = 0.0;
std::cout << x / y;              // ⚠️ для double НЕ падает — печатает inf
std::cout << 0.0 / 0.0;          // ⚠️ и nan — «не число». Тоже без падения
```

С дробными коварнее, чем с целыми: программа не падает, а продолжает считать — и разносит `inf`/`nan` по всем последующим формулам. Самое неприятное: **`nan` не сравним ни с чем.**

```cpp
#include <cmath>

double avg = 0.0 / 0.0;              // так получается nan: ноль делим на ноль

std::cout << (avg > 100) << "\n";    // → 0   ложь
std::cout << (avg <= 100) << "\n";   // → 0   ❗ ТОЖЕ ложь — оба сравнения неверны разом
std::cout << (avg == avg) << "\n";   // → 0   nan не равен даже самому себе

std::cout << std::isnan(avg) << "\n";    // → 1   ✅ единственная честная проверка
std::cout << std::isinf(10.0 / 0.0);     // → 1   ✅ и отдельно для бесконечности
```

Из-за этого обычная проверка `if (avg > 0)` пропускает испорченное значение дальше, и программа печатает `nan` вместо ответа. Практическое правило: **среднее считай только после проверки, что элементов больше нуля.**

```cpp
std::vector<int> v;                            // пустой — пользователь ничего не ввёл

if (v.empty()) {                               // ✅ проверка ДО деления
  std::cout << "Нет данных\n";
  return 1;
}
double avg = static_cast<double>(sum) / static_cast<double>(v.size());   // сюда попадаем только с непустым вектором
```

### Удержать число в границах: `min`, `max`, `clamp`

Очень частая задача — не дать числу выйти за пределы: здоровье 0..100, громкость 0..1, координата в пределах экрана. Руками это писали через `if`, но короче и понятнее — `std::clamp` из `<algorithm>` (C++17):

```cpp
#include <algorithm>          // std::min, std::max, std::clamp
#include <iostream>

int main() {
  int hp = 120;
  hp = std::clamp(hp, 0, 100);      // прижать к диапазону 0..100
  std::cout << hp << "\n";          // → 100

  int a = 3;
  int b = 7;
  std::cout << std::min(a, b) << " " << std::max(a, b) << "\n";   // → 3 7

  double volume = 1.4;
  volume = std::clamp(volume, 0.0, 1.0);   // → 1.0
  std::cout << volume << "\n";
  return 0;
}
```

`std::clamp(x, lo, hi)` возвращает `lo`, если `x` меньше `lo`; `hi`, если больше `hi`; иначе сам `x`. Важно: **все три аргумента должны быть одного типа** — `std::clamp(volume, 0, 1)` с `int`-границами не соберётся, нужно `0.0` и `1.0`. Больше про `<algorithm>` — в разделе [Итераторы и алгоритмы](07-algoritmy.md).

### Сводка

| Ловушка | Пример | Итог | Как чинить |
|---|---|---|---|
| целочисленное деление | `7 / 2` | `3` | `7 / 2.0` или `1.0 * a / b` |
| переполнение | `n * (n + 1)` в `int` | молча уходит в минус | `1LL * n * (n + 1)` |
| `%` с минусом | `-7 % 3` | `-1` | `std::abs(n) % 3` |
| деление на ноль (целые) | `x / 0` | падение | проверка `if (d != 0)` |
| сравнение `double` | `0.1 + 0.2 == 0.3` | `false` | `std::abs(a - b) < 1e-9` |

## 6. Сравнения и логика

```cpp
==  !=  <  >  <=  >=      // сравнение — результат bool (true/false)
&&  ||  !                 // И, ИЛИ, НЕ — для условий
&   |                     // побитовые — для битов, НЕ для условий
```

```cpp
int age = 20;

bool isAdult = (age >= 18);              // результат сравнения можно сохранить
std::cout << isAdult << "\n";            // → 1
std::cout << std::boolalpha << isAdult;  // → true   (читаемее при отладке)
```

### Ошибка 1: присваивание вместо сравнения

```cpp
int x = 3;

if (x = 5) {                    // ❌ ПРИСВОИЛИ 5 и проверили «5 != 0» → всегда true
  std::cout << "равно пяти\n";  //    напечатается, хотя x был 3. И x теперь 5!
}

if (x == 5) {                   // ✅ сравнение
  std::cout << "равно пяти\n";
}
```

Компилятор с `-Wall` предупредит: `suggest parentheses around assignment used as truth value`. Ещё один повод не игнорировать предупреждения.

### Ошибка 2: побитовое ИЛИ вместо логического

```cpp
int a = 1, b = 2;

if (a == 1 | b == 2)     // ❌ побитовое ИЛИ: работает «почти правильно», но
  std::cout << "да\n";   //    вычисляет ОБЕ части всегда, и это ломает защиты (см. ниже)

if (a == 1 || b == 2)    // ✅ логическое ИЛИ
  std::cout << "да\n";
```

### Ленивость `&&` и `||` — это инструмент

Правая часть **не вычисляется**, если левая уже всё решила:

```cpp
// Защита от выхода за границы
if (i < v.size() && v[i] == target)     // ✅ если i вне границ, v[i] даже не тронут
  std::cout << "нашли\n";

if (v[i] == target && i < v.size())     // ❌ обратный порядок = обращение за границу

// Защита от деления на ноль
if (d != 0 && n / d > 2)                // ✅ при d == 0 деление не выполнится
  std::cout << "больше двух\n";

// Защита от пустого контейнера
if (!v.empty() && v.front() > 0)        // ✅
  std::cout << "первый положительный\n";
```

С `|` и `&` (побитовыми) эти защиты не работают — они всегда вычисляют обе стороны.

### Цепочки сравнений — так нельзя

```cpp
int x = 15;

if (1 < x < 10)              // ❌ компилируется, но считает так: (1 < x) → true(1),
  std::cout << "в диапазоне\n";  //   потом 1 < 10 → true. Условие ИСТИННО для любого x!

if (x > 1 && x < 10)         // ✅ каждое сравнение — отдельно
  std::cout << "в диапазоне\n";
```

### `!` и инверсия условий

```cpp
bool found = false;

if (!found)                        // «если НЕ найдено»
  std::cout << "не нашли\n";
```

Часто условие проще написать сначала «как думаешь», а потом перевернуть. Переворачивать помогают **правила де Моргана**:

```
!(a && b)   то же самое, что   !a || !b        // отрицание «и» → «или» из отрицаний
!(a || b)   то же самое, что   !a && !b        // отрицание «или» → «и» из отрицаний
```

Обрати внимание: при переносе `!` внутрь скобок **`&&` и `||` меняются местами**. Забыть про это — популярный способ получить условие, срабатывающее наоборот.

Как это выглядит на живом примере — проверка «число вне диапазона 1..10»:

```cpp
int x = 15;

// Способ 1: описываем «внутри» и переворачиваем целиком
bool inRange = (x >= 1 && x <= 10);
if (!inRange)
  std::cout << "вне диапазона\n";        // → вне диапазона

// Способ 2: то же самое, развёрнутое по де Моргану
if (x < 1 || x > 10)                     // !(x >= 1) → x < 1;  !(x <= 10) → x > 10;  && → ||
  std::cout << "вне диапазона\n";        // → вне диапазона
```

Оба варианта дают одно и то же на любом `x`. Второй короче, но первый честнее показывает мысль: сначала «что считается правильным», потом «а если не так». Пока условие сложное — пиши первым способом, компилятор всё равно соберёт их одинаково.

**Частая ошибка при перевороте:**

```cpp
// Хотим: «НЕ (положительное И чётное)»
if (!(x > 0 && x % 2 == 0))       // ✅ так — точно верно
if (x <= 0 || x % 2 != 0)         // ✅ и так — развёрнуто правильно
if (x <= 0 && x % 2 != 0)         // ❌ забыли поменять && на ||:
                                  //    для x = 7 условие ложно, хотя должно быть истинно
```

> Когда сомневаешься — не переворачивай в уме. Заведи `bool` с понятным именем и поставь перед ним `!`. Это всегда правильно и всегда читается.

### Биты и флаги

`&`, `|`, `^`, `~`, `<<`, `>>` работают не с условиями, а с **отдельными битами** числа. Главное применение на практике — **флаги**: каждый бит хранит одну «галочку», и в одном числе умещается набор состояний. В геймдеве так задают маски ввода, слои коллизий, способности:

```cpp
#include <iostream>

int main() {
  // Каждый флаг — свой бит. 1u << n — единица, сдвинутая на n позиций влево.
  constexpr unsigned CAN_JUMP = 1u << 0;   // 0001
  constexpr unsigned CAN_SWIM = 1u << 1;   // 0010
  constexpr unsigned CAN_FLY  = 1u << 2;   // 0100

  unsigned abilities = CAN_JUMP | CAN_SWIM;   // включить два флага сразу → 0011
  abilities |= CAN_FLY;                       // добавить флаг
  abilities &= ~CAN_SWIM;                     // снять флаг (И с инверсией)

  if (abilities & CAN_JUMP)                   // проверить флаг: бит стоит?
    std::cout << "может прыгать\n";
  std::cout << (abilities & CAN_FLY ? "летает\n" : "не летает\n");
  return 0;
}
```

| Оператор | Что делает | Зачем |
|---|---|---|
| `a & b` | И по битам | проверить/оставить биты (`x & FLAG`) |
| `a \| b` | ИЛИ по битам | включить биты (`x \|= FLAG`) |
| `a ^ b` | исключающее ИЛИ | переключить биты |
| `~a` | инверсия всех битов | вместе с `&` — снять флаг |
| `a << n` | сдвиг влево | быстрое умножение на 2ⁿ, задать бит |
| `a >> n` | сдвиг вправо | деление на 2ⁿ |

Для битовых трюков бери **`unsigned`**: у знаковых типов сдвиги и старший бит ведут себя коварно. Не путай `&`/`|` (биты) с `&&`/`||` (условия) — это [ошибка 2](#ошибка-2-побитовое-или-вместо-логического) выше.

## 7. Ветвления

### `if` / `else if` / `else`

```cpp
int score = 75;

if (score >= 90) {                        // проверки идут СВЕРХУ ВНИЗ,
  std::cout << "Отлично\n";               // до первой подходящей
} else if (score >= 75) {
  std::cout << "Хорошо\n";                // → сюда, 75 >= 75
} else if (score >= 60) {
  std::cout << "Удовлетворительно\n";     // сюда уже не дойдёт
} else {
  std::cout << "Плохо\n";                 // если ни одно не подошло
}
```

Порядок важен. Если начать с `score >= 60`, туда провалится и 95, и 75 — всё станет «удовлетворительно».

### Всегда ставь фигурные скобки

```cpp
if (x > 0)
  std::cout << "положительное\n";
  std::cout << "и ещё строка\n";     // ❌ это УЖЕ НЕ внутри if — выполнится всегда

if (x > 0) {                         // ✅ со скобками такой ошибки не бывает
  std::cout << "положительное\n";
  std::cout << "и ещё строка\n";
}
```

### После сообщения об ошибке ставь `return`

```cpp
int n = readInt("Введите положительное число: ");

if (n <= 0) {
  std::cout << "Число должно быть положительным\n";
  // ❌ забыли return — программа поедет считать дальше с плохим n
}
double root = std::sqrt(n);            // для n = -5 получим NaN и молчаливую чушь
```

```cpp
if (n <= 0) {
  std::cout << "Число должно быть положительным\n";
  return 1;                            // ✅ выходим из main с кодом ошибки
}
double root = std::sqrt(n);            // сюда попадаем только с нормальным n
```

Внутри функции — то же самое, только возвращаешь подходящее значение:

```cpp
bool isValid(int n) {
  if (n < 0) {
    std::cout << "Отрицательное\n";
    return false;                      // ✅ дальше проверять нечего
  }
  return n < 1000;
}
```

### Тернарный оператор — короткий `if`/`else`

```cpp
int year = 2024;

// Обычная запись
int days;
if (isLeapYear(year))
  days = 29;
else
  days = 28;

// То же самое одной строкой: условие ? если_да : если_нет
int days2 = isLeapYear(year) ? 29 : 28;      // → 29

std::cout << (n % 2 == 0 ? "чётное" : "нечётное") << "\n";   // прямо в выводе
std::cout << "Найдено: " << (found ? "да" : "нет") << "\n";
```

Бери тернарник, когда выбираешь **одно значение из двух**. Не вкладывай его друг в друга — читаемость падает мгновенно.

### `switch` — выбор из фиксированного списка

```cpp
int month = 3;
int days = 0;

switch (month) {              // проверяемое значение — целое или char
case 1:                       // «если month == 1»
case 3:                       // несколько case подряд = «или то, или то»
case 5:
case 7:
case 8:
case 10:
case 12:
  days = 31;
  break;                      // ⚠️ без break провалится в следующий case
case 4:
case 6:
case 9:
case 11:
  days = 30;
  break;
case 2:
  days = isLeapYear(year) ? 29 : 28;
  break;
default:                      // если ни один case не подошёл
  std::cout << "Нет такого месяца\n";
  break;
}

std::cout << days << "\n";    // → 31
```

**Забытый `break` — классический баг:**

```cpp
switch (choice) {
case 1:
  std::cout << "Первый\n";     // ❌ нет break
case 2:
  std::cout << "Второй\n";     // при choice == 1 напечатается И ЭТО
  break;
}
// choice = 1  →  Первый
//                Второй
```

> Если провал в следующий `case` нужен **намеренно**, пометь это место атрибутом `[[fallthrough]];` (C++17) — тогда и читателю, и компилятору ясно, что `break` не забыт, а пропущен нарочно.

**`switch` для меню — типичное применение:**

```cpp
std::cout << "1 — добавить\n2 — удалить\n3 — выход\n";
int choice = readInt("Выбор: ");

switch (choice) {
case 1:
  addItem();
  break;
case 2:
  removeItem();
  break;
case 3:
  std::cout << "Выход\n";
  return 0;
default:
  std::cout << "Нет такого пункта\n";
  break;
}
```

> `switch` работает только с целыми и `char`. **Со `std::string` — не работает**, там нужен `if / else if`.

### `enum class` — имена вместо магических чисел

В примере выше `case 1:` и `case 2:` ничего не говорят читателю. Через месяц придётся листать вверх, чтобы вспомнить, что такое «2». `enum class` даёт числам имена:

```cpp
enum class Menu {          // новый тип с фиксированным списком значений
  Add = 1,                 // номера задаём сами — они совпадают с пунктами меню
  Remove = 2,
  Quit = 3
};

int choice = readInt("Выбор: ");
Menu action = static_cast<Menu>(choice);   // число от пользователя → значение перечисления

switch (action) {
case Menu::Add:                            // ✅ читается без пояснений
  std::cout << "Добавляем\n";
  break;
case Menu::Remove:
  std::cout << "Удаляем\n";
  break;
case Menu::Quit:
  std::cout << "Выход\n";
  return 0;
}
```

Три причины, по которым это лучше голых чисел:

```cpp
// 1. Компилятор напомнит о забытом варианте.
//    Если добавить в Menu пункт Edit и не дописать case — с -Wall придёт предупреждение:
//    warning: enumeration value 'Edit' not handled in switch

// 2. Типы не перепутаются между собой
enum class Color { Red, Green };
enum class Fruit { Apple, Banana };
Color c = Color::Red;
if (c == Fruit::Apple) { }        // ❌ error — и это хорошо: сравнение бессмысленно

// 3. Имя видно в отладчике: Menu::Remove вместо безликой двойки
```

Значения по умолчанию нумеруются с нуля: в `enum class Color { Red, Green, Blue }` это `0`, `1`, `2`.

Обратно в число — только явно, `enum class` сам не превращается в `int`:

```cpp
std::cout << static_cast<int>(Menu::Quit);   // → 3
std::cout << Menu::Quit;                     // ❌ error: no match for 'operator<<'
```

> Старая форма без `class` (`enum Menu { Add, Remove };`) молча превращается в числа и рассыпает имена в общую область — из-за этого два перечисления с полем `Red` конфликтуют. Встретишь её в любом старом коде, но сам пиши `enum class`.

## 8. Циклы

### Три вида и когда какой

```cpp
// for — когда известно, СКОЛЬКО РАЗ
for (int i = 0; i < 5; ++i)          // старт; условие продолжения; шаг
  std::cout << i << " ";             // → 0 1 2 3 4

// while — когда неизвестно, условие проверяется ДО тела
int n = 1234;
int sum = 0;
while (n > 0) {                      // пока есть цифры
  sum += n % 10;                     // берём последнюю
  n /= 10;                           // отбрасываем её
}
std::cout << sum;                    // → 10

// do while — тело выполнится ХОТЯ БЫ РАЗ, условие проверяется ПОСЛЕ
int choice = 0;
do {
  choice = readInt("Пункт меню: ");  // меню надо показать хотя бы один раз
} while (choice != 3);               // повторяем, пока не выбран выход
```

### `break` и `continue`

```cpp
// break — выйти из цикла совсем
for (int i = 0; i < 10; ++i) {
  if (i == 5)
    break;                     // на пятом шаге бросаем всё
  std::cout << i << " ";       // → 0 1 2 3 4
}

// continue — пропустить остаток витка, перейти к следующему
for (int i = 0; i < 10; ++i) {
  if (i % 2 != 0)
    continue;                  // нечётные пропускаем
  std::cout << i << " ";       // → 0 2 4 6 8
}
```

### Какой цикл когда

| Что нужно | Как писать |
|---|---|
| Просто прочитать элементы | `for (int x : v)` |
| Элементы большие (`string`, `vector`, `struct`) | `for (const auto &x : v)` |
| Менять элементы на месте | `for (auto &x : v)` |
| Нужен номер элемента | `for (std::size_t i = 0; i < v.size(); ++i)` |
| Идём по словарю | `for (const auto &[key, value] : m)` |
| Не с начала / с шагом 2 / с конца | обычный `for` с индексами |

```cpp
std::vector<std::string> names = {"Аня", "Борис"};

for (std::string name : names)          // ⚠️ копирует каждую строку целиком
  std::cout << name << " ";

for (const std::string &name : names)   // ✅ ссылка: без копий, менять нельзя
  std::cout << name << " ";

for (const auto &name : names)          // ✅ то же самое, но короче
  std::cout << name << " ";

for (auto &name : names)                // ✅ ссылка без const: можно менять
  name += "!";                          // → Аня!  Борис!
```

Для `int` и `double` копия ничего не стоит — пиши как удобно. Для строк, векторов и структур — всегда `const auto &`.

### Типовые ситуации

**Сумма и среднее:**

```cpp
std::vector<int> marks = {5, 4, 5, 3};
int sum = 0;

for (int m : marks)                                   // проходим по всем оценкам
  sum += m;                                           // копим сумму

double avg = static_cast<double>(sum) / static_cast<double>(marks.size()); // ⚠️ cast, иначе целочисленное деление
std::cout << sum << " " << avg << "\n";               // → 17 4.25
```

**Поиск с флагом:**

```cpp
std::vector<int> v = {3, 8, 12, 5};
int target = 12;
bool found = false;                 // флаг «нашли ли»
std::size_t position = 0;

for (std::size_t i = 0; i < v.size(); ++i) {
  if (v[i] == target) {
    found = true;
    position = i;
    break;                          // нашли — дальше искать незачем
  }
}

if (found)
  std::cout << "Позиция: " << position << "\n";   // → Позиция: 2
else
  std::cout << "Не найдено\n";
```

**Максимум и его номер:**

```cpp
std::vector<int> v = {3, 8, 12, 5};
int best = v[0];                    // ⚠️ считаем, что вектор непустой
std::size_t bestIndex = 0;

for (std::size_t i = 1; i < v.size(); ++i) {   // со ВТОРОГО элемента
  if (v[i] > best) {
    best = v[i];
    bestIndex = i;
  }
}
std::cout << best << " на позиции " << bestIndex;   // → 12 на позиции 2
```

**Вложенный цикл — таблица умножения:**

```cpp
for (int i = 1; i <= 3; ++i) {           // внешний цикл — строки
  for (int j = 1; j <= 3; ++j)           // внутренний — столбцы, крутится полностью
    std::cout << std::setw(4) << i * j;  //   на КАЖДОМ витке внешнего
  std::cout << "\n";                     // перевод строки — после внутреннего цикла
}
// →    1   2   3
// →    2   4   6
// →    3   6   9
```

**Накопление строки:**

```cpp
std::string line;
for (int i = 1; i <= 5; ++i) {
  line += std::to_string(i);            // число → строка и приклеиваем
  if (i < 5)                            // разделитель — между элементами,
    line += ", ";                       // но не после последнего
}
std::cout << line;                      // → 1, 2, 3, 4, 5
```

### Типовые ошибки

```cpp
// 1. Лишний виток: <= вместо <
for (int i = 0; i <= n; ++i)       // ❌ выполнится n+1 раз
for (int i = 0; i < n; ++i)        // ✅ ровно n раз

// 2. while с отрицательным числом
int n = -1234;
while (n > 0) { ... }              // ❌ не выполнится ни разу
n = std::abs(n);                   // ✅ сначала модуль
while (n > 0) { ... }

// 3. Изменение счётчика внутри тела
for (int i = 0; i < 10; ++i) {
  ++i;                             // ❌ шаг стал 2, читателю неочевидно
}

// 4. Изменение контейнера во время перебора
for (int x : v)
  if (x > 10)
    v.push_back(x);                // ❌ вектор переедет в памяти, цикл сломается

std::vector<int> toAdd;            // ✅ копим отдельно
for (int x : v)
  if (x > 10)
    toAdd.push_back(x);
for (int x : toAdd)                // и добавляем после
  v.push_back(x);

// 5. Бесконечный цикл: забыли изменить условие
int n = 10;
while (n > 0)
  std::cout << n;                  // ❌ n не меняется — печатает вечно
while (n > 0)
  std::cout << n--;                // ✅ n уменьшается
```

### Заготовки, которые нужны постоянно

```cpp
// Разбор числа на цифры
int n = std::abs(-1234);           // сначала модуль!
int digitSum = 0;
int digitCount = 0;
while (n > 0) {
  digitSum += n % 10;              // последняя цифра
  ++digitCount;
  n /= 10;                         // отбрасываем её
}
// digitSum = 10, digitCount = 4

// Переворот числа
int n = 1234;
int reversed = 0;
while (n > 0) {
  reversed = reversed * 10 + n % 10;   // сдвигаем влево и приклеиваем цифру
  n /= 10;
}
std::cout << reversed;                 // → 4321

// Проверка на простоту
bool isPrime(int n) {
  if (n < 2)
    return false;
  for (int i = 2; 1LL * i * i <= n; ++i)   // до корня из n; 1LL — от переполнения
    if (n % i == 0)
      return false;                        // нашли делитель — не простое
  return true;
}
```
