## Игровой цикл

Любая игра — это один цикл, который крутится, пока игра идёт: **показать мир → прочитать ход → обновить состояние**. Ровно те же три шага, что «ВВОД → РАСЧЁТ → ВЫВОД», только по кругу.

```cpp
while (running) {              // пока идёт игра
  render(state);               // 1. показать мир на экране
  Command cmd = readInput();   // 2. прочитать ход игрока
  update(state, cmd);          // 3. обновить состояние по ходу
}
```

Всё состояние игры (где кто стоит, сколько очков, жив ли игрок) держат в переменных и структурах — и меняют только в `update`. `render` ничего не меняет, только рисует; `input` только читает. Такое разделение спасает от путаницы, когда игра растёт.

## Сущности: `struct` + `vector`

Врагов, монеты, пули удобно описывать одной [структурой](08-struct-fayly.md#19-struct), а всех разом хранить в [векторе структур](06-konteynery.md#вектор-структур--самая-частая-форма):

```cpp
struct Enemy {
  int x = 0;
  int y = 0;
  int hp = 3;
  bool alive = true;
};

std::vector<Enemy> enemies = {{1, 0}, {4, 2}, {6, 1}};

for (Enemy &e : enemies) {     // ссылка &, потому что МЕНЯЕМ каждого
  if (!e.alive) continue;      // мёртвых пропускаем
  e.x += 1;                    // например, ползут вправо
}
```

Добавить врага — `enemies.push_back({8, 3})`, убрать погибших — `std::erase_if(enemies, [](const Enemy &e){ return !e.alive; })`. Так один цикл обрабатывает сколько угодно объектов.

## Случайность: `<random>`

Кубик, случайная клетка, шанс выпадения предмета — это `<random>`. Не бери старый `rand()`: он хуже по качеству и требует ручной возни. Современный способ — **генератор** плюс **распределение**:

```cpp
#include <iostream>
#include <random>

int main() {
  std::mt19937 rng(std::random_device{}());        // генератор, засеянный случайно
  std::uniform_int_distribution<int> dice(1, 6);    // равномерно от 1 до 6 включительно

  for (int i = 0; i < 5; ++i)
    std::cout << dice(rng) << " ";                  // например: 3 6 1 4 2
  std::cout << "\n";
  return 0;
}
```

`rng` — источник «сырых» случайных чисел, `dice` превращает их в нужный диапазон. Одно распределение можно звать сколько угодно раз; для разных диапазонов заводят разные распределения (`randRow`, `randCol` в примере ниже).

## Поле: сетка из строк

Двумерное поле удобно держать как [вектор строк](06-konteynery.md#таблица-чисел-vectorvectorint): каждая строка — ряд клеток, символ — что в клетке. Индексируется `grid[y][x]` (сначала ряд, потом столбец):

```cpp
std::vector<std::string> grid = {
    "........",
    "...$....",     // $ — монета
    "........",
};

grid[1][3] = '.';                       // подобрали монету — клетка опустела

for (const std::string &row : grid)     // отрисовать поле построчно
  std::cout << row << "\n";
```

Латиница и знаки (`.`, `$`, `@`, `#`) тут кстати: они по одному байту, поэтому `grid[y][x]` работает как ожидаешь (в отличие от [кириллицы](05-stroki.md#10-stdstring)).

## Всё вместе: «Собери монеты»

Соберём кирпичики в целую (хоть и крохотную) игру: поле, игрок `@`, три монеты `$` в случайных клетках; ходишь `w`/`a`/`s`/`d`, собираешь монеты, игра заканчивается, когда собраны все.

```cpp
#include <windows.h>       // русские буквы в консоли Windows
#include <iostream>
#include <random>
#include <string>
#include <vector>

struct Player {
  int x = 0;
  int y = 0;
  int score = 0;
};

int main() {
  SetConsoleCP(CP_UTF8);
  SetConsoleOutputCP(CP_UTF8);

  const int H = 5;                       // высота поля
  const int W = 8;                       // ширина
  std::vector<std::string> grid(static_cast<std::size_t>(H),
                                std::string(static_cast<std::size_t>(W), '.'));

  // случайность: генератор + два распределения (для ряда и столбца)
  std::mt19937 rng(std::random_device{}());
  std::uniform_int_distribution<int> randRow(0, H - 1);
  std::uniform_int_distribution<int> randCol(0, W - 1);

  // разбросать 3 монеты по пустым клеткам
  int coins = 0;
  while (coins < 3) {
    int r = randRow(rng);
    int c = randCol(rng);
    char &cell = grid[static_cast<std::size_t>(r)][static_cast<std::size_t>(c)];
    if (cell == '.') { cell = '$'; ++coins; }
  }

  Player p;
  int left = coins;

  while (left > 0) {                      // ИГРОВОЙ ЦИКЛ
    // 1. render — показать поле
    for (int y = 0; y < H; ++y) {
      for (int x = 0; x < W; ++x) {
        if (x == p.x && y == p.y) std::cout << '@';
        else std::cout << grid[static_cast<std::size_t>(y)][static_cast<std::size_t>(x)];
      }
      std::cout << '\n';
    }
    std::cout << "Счёт: " << p.score << " | ход (w/a/s/d): ";

    // 2. input — прочитать ход
    char cmd = 0;
    if (!(std::cin >> cmd)) break;        // ввод кончился — выходим

    // 3. update — подвинуть игрока в пределах поля
    int nx = p.x;
    int ny = p.y;
    if (cmd == 'w') --ny;
    else if (cmd == 's') ++ny;
    else if (cmd == 'a') --nx;
    else if (cmd == 'd') ++nx;
    if (nx >= 0 && nx < W && ny >= 0 && ny < H) { p.x = nx; p.y = ny; }

    // подобрать монету, если встали на неё
    char &here = grid[static_cast<std::size_t>(p.y)][static_cast<std::size_t>(p.x)];
    if (here == '$') { here = '.'; ++p.score; --left; }
  }

  std::cout << "Готово! Собрано монет: " << p.score << "\n";
  return 0;
}
```

Что где узнаёшь: **игровой цикл** — `while (left > 0)`; **сущность** — `struct Player`; **случайность** — `<random>` и два распределения; **поле** — `std::vector<std::string>`; **ввод/UB-защита** — проверка границ перед движением. Дальше эту же схему масштабируют: врагов и монеты держат в `vector`, каждый кадр обновляют в цикле, а `render` рисует всех. Движок (когда до него дойдёшь) забирает на себя `render` и ввод, а `update` с состоянием игры остаётся твоим.
